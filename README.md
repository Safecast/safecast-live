# Safecast Live

Safecast Live revives [safestream](https://github.com/Safecast/safestream), the project behind the original [Safecast Live](https://safecast.org/safecast-live/).

The project turns incoming Safecast radiation and air quality readings into sound. Each reading can trigger a sample from a selected sound pack, creating an evolving composition shaped by what the sensors report and when their readings arrive.

The revival brings back the original sound packs and rebuilds the receiver and browser player around live Radnote and Airnote events. Development is underway.
